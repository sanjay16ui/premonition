# PREMONITION — User Manual

## Getting Started

1. Open the web app at `http://localhost:5173`
2. Navigate via the sidebar to your role-appropriate views
3. For mobile, install the Expo app and sign in

## Clinician Workflow

1. **Live Monitoring** (`/monitoring`) — view real-time ICU patient risk scores
2. **Patient Risk** (`/patient-risk`) — run predictions on individual patients
3. **SHAP Explain** (`/explain`) — understand model feature contributions
4. **AI Copilot** (`/copilot`) — ask clinical questions with cited sources
5. **Patient Copilot** (`/copilot/patient`) — generate summaries and handover notes

## Executive Workflow

1. **Analytics Dashboard** (`/analytics`) — KPIs, trends, capacity graphs
2. **Executive Copilot** (`/copilot/executive`) — AI hospital status summary
3. **3D Executive** (`/executive-3d`) — immersive command center

## Alert Response

1. Check **Alert Center** in Live Monitoring
2. Use **Explain Alert** via Copilot for context
3. Review SHAP factors for the patient
4. Follow clinical protocol recommendations

## Mobile App

- **Dashboard** — key metrics at a glance
- **Monitoring** — live patient list (5s refresh)
- **Alerts** — push notification center
- **Copilot** — clinical AI chat
- **Executive** — hospital KPI summary
